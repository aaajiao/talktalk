# Qwen 克隆音色一致性：社区方案核查

日期：2026-11-05。对应 TalkTalk 1.0.8（9）、Qwen3-TTS 1.7B Base 8bit、MLX 流式 ICL。本文是排查依据，不表示问题已经解决。

用户报告不同句子像换了说话人，包含其他男声、女声。1.0.7 的档案身份校验没有消除这一听感；发布 1.0.8 前的小样本 A/B 中，用户选择重复惩罚 1.05 比 1.5 更像本人。后者是当前已知改善，不是连续会议音色稳定性的验收。

## 结论与优先级

本轮检查 Qwen 官方仓库、mlx-audio 的 issue/实际补丁、第三方应用及社区作者的实测。没有找到可直接移植、已证明能在我们的实时 MLX 路径根治逐句换人的方案。

最值得优先核对的是参考录音与参考文字的准确对应。其次才是同一人的不同参考片段、目标语言参考或生成/解码的有界对照。暂不增加逐句整段重生成、声纹门槛、新训练流程或量化档位设置。

### 如何判断“像本人”

2026-10-16 的研究 [Beyond the Benchmark](https://arxiv.org/html/2610.23678v1) 比较 ICL 与 X-Vector，发现准确转写对 ICL 尤其重要，自动指标排序与听者并不完全一致。研究采用 BF16、英语语料，小规模听测，不能直接外推我们中→英/德 8bit 路径的故障率。

因此已有 clone 路由日志、声纹余弦或 F0 只能作辅助证据。应分别记录听感身份、内容是否正确、首声等待和断句；用户听到换人时，不能用高余弦分数否定。X-Vector 也不是已验证优于 ICL 的替换方案。

## 下一步最小排查

1. 核对既有参考录音与实际文本是否完整匹配、句尾是否自然。确认问题后才修改参考，不先让用户重录，不自动用未经核实的 ASR 文本替代。
2. 若参考无误而 1.0.8 仍换声，用少量固定英/德句做有界对照，一次只换一个因素。可优先分离同一生成 codec 的流式/整段解码，判断变化来自生成还是解码；需要相关诊断支持时再做最小实现。
3. 只有前两步不足时，比较本人不同参考片段/同语言参考。微调、更换模型和逐句自动重试暂不纳入。

用户随后提出重新录入、更长内容。重录可作为候选对照，保留旧档案，听验后再决定替换。当前 5–12 秒是产品的有效时长检查，不是 Qwen 的模型限制；过长时提示读快，也可能让录音偏离自然会议语速。若调整录入体验，可考虑约 10–20 秒自然完整语音的候选范围，但它只是待比较的产品建议，不是官方最佳时长，本轮未修改限制。不能由“短参考配错文字更易退化”推导“录得越长音色越稳定”。

本轮只读研究并更新文档，未新增录音、上传声音、运行模型或改动推理代码。音频与个人指标继续留在仓库外；没有压力测试，也不据此发布新版本。

后续用户明确选择 10–20 秒并要求调整稿件、出正式版供重录。1.0.9 据此采用 `zh-v2` 的 71 字新稿和 10–20 秒有效时长范围，原始录音上限 25 秒。旧档案继续可用；重录试听失败保留旧档案。此为上述研究后的产品改动，仍待用户确认新录音的实际音色。

## 重录后的反馈与长句方向

用户随后表示新录音效果更差，并明确要求把重复惩罚从 1.05 恢复 1.5，1.0.10 据此回退该参数。此前“保留旧档案”只覆盖新档案保存前；现有提交实现保存成功后删除旧档案，没有历史恢复槽。查找未找到旧参考/conditioning 副本，故不能宣称已恢复旧声音。新档案现已独立备份，A/B 合成音频不当作原参考使用。

用户观察短句发言较好、长句更容易换声。进一步检查：录音切片约 4.5 秒，但翻译结果不受这个秒数限制，单次 TTS 对整段目标文本连续生成到 EOS；积压摘要另可合并原文，但最近三场未触发它。最近 64 token 的重复惩罚窗口真实生效，decoder 的 72 帧窗口也不意味着主生成器在该时刻忘记参考；暂停调度后继续原生成器，已释放音频后不换种子重试。现有保护能处理跑飞/回声，不能识别“内容正确但声线偏离”。这些区分支持补齐无正文长度诊断，尚不足以证明需要更短切句。

新增社区证据也存在相反结果：[oMLX #516](https://github.com/jundot/omlx/issues/516) 的 CustomVoice 用户报告独立短请求更容易逐段变化；它不是我们 Base 克隆路径的对照。[Voicebox #964](https://github.com/jamiepine/voicebox/pull/964) 用缩块缓解长中文静音后噪声，针对旧版 MLX、离线长文，不能把其字符数或整句重试直接搬入会议。[Qwen #80](https://github.com/QwenLM/Qwen3-TTS/issues/80) 还有德语直接引语/开头引号相关观察，未经确认。因此暂不全局去标点、不固定套用 200 字切块，也不假设长发言必然等于一次长 TTS。

后续带长度元数据的自然发言支持进一步缩小方向：一轮连续发言在约 26.5 秒提交跨度内包含 5 次独立 TTS，每次只有 5–10 词、1.76–2.80 秒，均为停顿切分，没有合并。用户具体描述为“下一句像换了一个人”，应重点比较句间独立生成的一致性，而非假定单次生成太长。按住改点按的提交没有修改合成模型或分段器；它改变了发言控制方式，是否因更频繁的自动句界触发音色变化仍需对照，不能仅凭时间先后断言。
