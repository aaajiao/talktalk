# 当前状态与剩余工作

当前源码版本：**1.0.1（构建 2）**，以 `scripts/lib/versions.sh` 为准。
核心功能已集成；构建、资源检查和定向功能回归已有验证，但尚未完成跨应用、跨设备的真人会议验收。设计依据见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 已实现

- 会议同传与视频字幕两种场景；视频字幕不启用麦克风或默认输入切换。
- LISTEN：应用音频捕获、默认 Qwen / 可选与备用 Apple 识别、语言与 ASR 热切换、英/德原文与中文成对字幕。
- SPEAK：中文夹英语识别、英/德翻译、系统声音或“我的声音”、分段处理、有序播放及本次发言原译文显示。
- 会议默认原声；按住右 Option 关闭原声并翻译，松开等待全部工作与译音排空后恢复；虚拟麦、默认输入恢复及设备守卫已接入。
- 设置、8 步引导、声音录入与校准、术语表、云端开关、通知、告知语、组件管理与完全卸载入口。
- 元数据诊断、显式自检、可选择的转写/录音、本次字幕文字分析与有界报告工具；缺失指标显示未知。

## 已有验证与已知限制

- 软件检查覆盖策略、取消与代际隔离、环形缓冲、输出顺序、默认输入恢复及安装器的 fake 路径；不表示对应真实硬件场景全部通过。
- 本地试说已走通采集、识别、翻译、TTS 和实际首样本播放；尚不能替代第二设备收到译音的证明。
- 实际视频回放验证过字幕链路，仍观察到短碎句、专名误识别和积压时的丢弃；没有参考转写，不能据此给出识别或翻译准确率。
- 长段混说、短尾、德语句法、数字/术语与克隆音色仍需自然发言复验；自动数字检查不保证语义正确。
- 浏览器来源覆盖整个应用音频；来源选择在下一次启动会话生效。原文语言和 ASR 选择可即时切换，云翻译模型选择在下一场生效。
- 字幕诊断记录 AppKit 更新，不测光学显示延迟；SPEAK 缺可靠 voice-end 时不提供 EVS，原始首声间隔可能包含等待。
- 本地正式包的签名与资源检查已通过；尚未完成 Developer ID 签名、公证及公开二进制分发流程。
