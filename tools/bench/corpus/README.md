# M0 句子表

依据 `docs/ARCHITECTURE.md` §9、§14 M0 表、§5.4、§12.1。每份表是 JSON，`items[].id` 是唯一 id。`python3 validate.py` 检查数量和词数约束。

| 文件 | 对应测量 | 要不要录音 | 怎么用 |
|---|---|---|---|
| `voice_ref.json` | T1 参考扫描、T7、T17 | 要（你本人） | 不含稿子，只指向 §9.1 的固定稿 zh-v1（42 字）。6 / 8 / 10 / 12 s 四档怎么得到：待 T1 定 |
| `t1_en.json`、`t1_de.json` | T1 TTS 空载 | 不要（喂给 TTS 的文本） | 各 50 句，1–25 词；01–30 是 ≤3 词短句，31–50 是长句。每个组合都全部合成一遍，按 id 分组统计 |
| `t7_en.json`、`t7_de.json` | T7、T7b | 不要（喂给 TTS 的文本） | 各 30 句；用你自己的中文参考合成，再 ASR 回读 WER、算相似度、你盲评。01 号是 §9.2 的试听句 |
| `t5.json` | T5 SPEAK ASR | 要（100 段） | 每段约 1.5–6 s，30 段中英夹杂（`mixed`，`terms` 列出英文术语），覆盖百分比、金额、日期、时长、其他数字（`tags`），2 段纯语气词（`filler`）。有 `spoken` 的条目含阿拉伯数字，按 `spoken` 读；CER 参考文本 = `spoken`，否则 `text` |
| `t17.json` | T17 端到端 | 要（约 9 次按键） | `zh.wav` 的稿子，每条 press 对应一次按住说话，`expect` 写明测什么，`gap_after_s` 是条目之间的静音，`tap` 是轻点（不录）。括号里的提示不要读出来 |

## 录音

录音在 TalkTalk-Dev.app 里做，不另有独立工具：

- `--bench enroll`：录声音参考（走 §9.2 的录制流程）；
- `--bench record`：录 T5 和 T17 的测试段；

入口由 talktalk-voice 会话实现。录音是个人数据，不进 git、不上传，存放位置以 app 的实现为准。录音环境按 §9.2：安静房间、内建麦或 USB 麦（不用蓝牙）。

## 预计用时（估）

声音参考 ≈ 5 min；T5 100 段 ≈ 25–35 min（含重录）；T17 ≈ 10 min。建议分三次。先录声音参考，T1 和 T7 都要用。
